# _unused

Nothing in the app imports these files. They were in the project from the start
(a ready-made shadcn/ui kit, `CustomButton`, `ImageWithFallback`) and are kept only in case someone needs them later.

- Need one of them? Move it into `atoms/`, `molecules/` or `organisms/` and import it from there.
- Sure you don't? You can delete this whole folder (the app still builds).
